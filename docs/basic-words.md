# 기초 단어 목록

보카 빈칸 시험의 오답(혼동 단어)이 "아는 단어"인지 가리는 기준이다. 기준은 **중학교 교과서 수준**이고, 넣을지 망설여지는 단어는 넣지 않았다 (300점대가 모른다고 보는 게 안전하다).

통과 규칙: **790단어장 표제어 ∪ 그 파생형 ∪ 이 목록**. 셋 다 아니면 교체 대상이다.

- 파생형은 기계로 판정한다. 접미사 -s·-es·-ed·-ing·-er·-or·-est·-ly·-tion·-ation·-sion·-ment·-ness·-able·-ible·-ful·-less·-al·-ity·-ive·-ance·-ence·-ist·-ize·-ship·-ee·-y 등을 최대 3번까지 떼고, 접두사 un-·re-·in-·im-·dis-·non-·pre-·mis-·over-·under-를 뗀다. 떼고 남은 말이 790단어장이나 이 목록에 있으면 통과다 (older = old + er, unhappy = un + happy).
- 2026-11-20 경계 단어 재검토: 처음 뺀 63개 중 중학 수준인 47개를 다시 넣었다 (mercy·jury·species·obvious·structure·process 등). substance·resident·opponent·slight·furious·burden·crush·lid·hose·mittens·plum·wardrobe·gadget·interior·trailer·carton 16개는 계속 뺀다.
- 790단어장 표제어에서 접미사 하나를 뗀 어근도 바탕으로 쓴다 (employee → employ → employer).
- 두 단어 이상인 오답(bar chart 등)은 기능어를 뺀 모든 단어가 통과해야 한다.
- 합성어는 파생형으로 보지 않는다 (placeholder ≠ place + holder).
- 생존 영어 트랙의 오답은 일부러 틀리게 만든 표현이라 이 규칙을 적용하지 않는다.

실행: `node tools/list-unknown-distractors.js` (교체 대상을 Day별로 출력)

목록에 단어를 넣거나 뺄 때는 아래 코드 블록만 고치면 된다. 한 줄에 같은 글자로 시작하는 단어를 공백으로 나눠 적는다.
